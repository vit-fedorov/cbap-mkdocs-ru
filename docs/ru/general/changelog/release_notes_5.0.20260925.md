# Сведения о выпуске 5.0 от 25.09.2026 {: #release_notes_5.0.20260925 }

## Введение {: #release_notes_5.0.20260925_intro }

**{{ productName }}** версии 5.0 от 25.09.2026 включает ряд новых возможностей, улучшений и исправлений по сравнению с [версией 5.0 от 04.08.2026][release_notes_5.0.20260804].

!!! warning "Обновление до версии 5.0 от 25.09.2026"

    Из-за изменения структуры конфигурационных файлов обновление до версии 5.0 от 25.09.2026 следует выполнять только посредством создания нового экземпляра ПО и подключения к нему базы данных обновляемого экземпляра.

## Ключевые изменения {: #release_notes_5.0.20260925_key_changes }

- **Аутентификация:** реализована аутентификация пользователей Active Directory по тикетам Kerberos: единый вход (SSO) настраивается параметрами конфигурационного файла экземпляра и не требует установки и настройки модуля SPNEGO в NGINX. Повышена стабильность аутентификации через Active Directory и Keycloak. <!-- 10625380 --> <!-- 10684323 --> <!-- 10689166 -->
- **{{ productNameArchitect }} и процессы:** улучшено сохранение, восстановление и просмотр версий диаграмм; обеспечено сохранение связей элементов с родительскими процессами в моделях при обновлении ПО. <!-- 10663591 --> <!-- 10687883 --> <!-- 10681999 -->
- **Интеграции и пути передачи данных:** повышена стабильность адаптеров обмена данными через {{ apacheKafkaVariants }} и RabbitMQ, импорта данных по протоколу OData, экспорта записей с атрибутами, хранящими несколько значений. <!-- 10677240 --> <!-- 10669993 --> <!-- 10697805 -->
- **Переменные и язык выражений:** в параметры сеанса добавлен признак устройства, с которого пользователь работает с системой. <!-- 10301171 -->

## Новые возможности и улучшения {: #release_notes_5.0.20260925_new_and_improved }

### Аутентификация {: #release_notes_5.0.20260925_auth }

- **Active Directory:** реализована аутентификация пользователей по тикетам Kerberos. Единый вход (SSO) полностью настраивается параметрами (`auth.kerberos.*`) в конфигурационном файле экземпляра **{{ productName }}** без установки и настройки модуля SPNEGO в NGINX. Поддерживаются два сценария: автоматический вход в домене и вход по кнопке на странице авторизации. <!-- 10625380 -->
- **Keycloak:** повышена стабильность аутентификации. <!-- 10689166 -->

### Интерфейс {: #release_notes_5.0.20260925_ui }

- **Запуск и перезапуск системы:** доработана страница, отображаемая во время запуска **{{ productName }}** и обновления базы данных: страница автоматически обновляется, пока сервисы не будут готовы, отображает состояние обновления базы данных и после завершения запуска переводит пользователя на страницу входа. <!-- 10659939 -->
- **Виджеты:** улучшено отображение данных. <!-- 10563508 -->

### Формы и атрибуты {: #release_notes_5.0.20260925_forms }

- **Атрибуты «Документ» и «Изображение»:** улучшена работа в режиме редактирования формы. <!-- 10292674 --> <!-- 10461838 -->
- **Ссылочные атрибуты:** уточнено отображение записей в выпадающих списках: архивированные записи больше не предлагаются для выбора на форме. <!-- 10656204 -->

### Списки и коллекции {: #release_notes_5.0.20260925_lists }

- **Коллекции:** значения связанных справочников отображаются в коллекциях независимо от того, архивирована ли запись справочника. <!-- 10453827 -->
- **Таблицы с группировкой:** улучшена работа формы расширенного поиска. <!-- 10538216 -->

### Переменные, сценарии и язык выражений {: #release_notes_5.0.20260925_scenarios }

- **Параметры сеанса:** добавлен признак устройства, с которого пользователь работает с системой (веб-интерфейс, мобильное приложение, мобильный веб-сайт, форма для внешних пользователей). Новый параметр доступен в языке выражений и позволяет настраивать правила отображения форм в зависимости от устройства пользователя, в том числе использовать его в вычисляемых атрибутах при работе через мобильный интерфейс. <!-- 10301171 --> <!-- 10652649 -->
- **Сценарии:** улучшена работа блока создания документа по шаблону внутри цикла по объектам. <!-- 10655807 -->

### {{ productNameArchitect }} и процессы {: #release_notes_5.0.20260925_architect_processes }

- **Конструктор диаграмм:** улучшено отображение при переключении между режимами просмотра и редактирования; повышена стабильность работы с версиями. <!-- 10677883 --> <!-- 10663591 --> <!-- 10687883 --> <!-- 10687962 -->

### Интеграции и пути передачи данных {: #release_notes_5.0.20260925_integrations_api }

- **Адаптеры и брокеры сообщений:**
    - повышена стабильность работы с брокерами сообщений; <!-- 10571425 --> <!-- 10677240 -->
    - реализован двусторонний маппинг альтернативных имён шаблонов и атрибутов в адаптере {{ apacheKafkaVariants }}; <!-- 10677404 -->
    - улучшена работа кластерной конфигурации. <!-- 10679931 -->
- **Импорт и экспорт данных:**
    - улучшен импорт данных в **{{ productName }}**; <!-- 10667182 --> <!-- 10669993 -->
    - повышена надежность экспорта записей через адаптер передачи данных при наличии атрибутов, хранящих несколько значений. <!-- 10697805 -->
- **Пути передачи данных:** повышена стабильность работы при выборе связанных ссылочных атрибутов из одного шаблона записи. <!-- 10700213 -->

### Производительность {: #release_notes_5.0.20260925_performance }

- **Формы:** повышена производительность операций с формами, содержащими большое количество виджетов. <!-- 10671355 -->

## Исправления {: #release_notes_5.0.20260925_fixes }

- **Инфраструктура и интеграции:** повышена стабильность работы адаптеров, брокеров сообщений, кластерной конфигурации, импорта и экспорта данных.
- **Приложения и интерфейс:** улучшена работа форм, списков, коллекций, виджетов, сценариев, конструктора диаграмм и **{{ productNameArchitect }}**.
