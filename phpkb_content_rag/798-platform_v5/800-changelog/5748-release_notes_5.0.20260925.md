# Сведения о выпуске 5.0 от 25.09.2026

## Введение

**Comindware Platform** версии 5.0 от 25.09.2026 включает ряд новых возможностей, улучшений и исправлений по сравнению с [версией 5.0 от 04.08.2026](https://kb.comindware.ru/article.php?id=5747).

Обновление до версии 5.0 от 25.09.2026

Из-за изменения структуры конфигурационных файлов обновление до версии 5.0 от 25.09.2026 следует выполнять только посредством создания нового экземпляра ПО и подключения к нему базы данных обновляемого экземпляра.

## Ключевые изменения

- **Аутентификация:** реализована аутентификация пользователей Active Directory по тикетам Kerberos: единый вход (SSO) настраивается параметрами конфигурационного файла экземпляра и не требует установки и настройки модуля SPNEGO в NGINX. Повышена стабильность аутентификации через Active Directory и Keycloak.
- **Корпоративная архитектура и процессы:** улучшено сохранение, восстановление и просмотр версий диаграмм; обеспечено сохранение связей элементов с родительскими процессами в моделях при обновлении ПО.
- **Интеграции и пути передачи данных:** повышена стабильность адаптеров обмена данными через Apache Kafka и RabbitMQ, импорта данных по протоколу OData, экспорта записей с атрибутами, хранящими несколько значений.
- **Переменные и язык выражений:** в параметры сеанса добавлен признак устройства, с которого пользователь работает с системой.

## Новые возможности и улучшения

### Аутентификация

- **Active Directory:** реализована аутентификация пользователей по тикетам Kerberos. Единый вход (SSO) полностью настраивается параметрами (`auth.kerberos.*`) в конфигурационном файле экземпляра **Comindware Platform** без установки и настройки модуля SPNEGO в NGINX. Поддерживаются два сценария: автоматический вход в домене и вход по кнопке на странице авторизации.
- **Keycloak:** повышена стабильность аутентификации.

### Интерфейс

- **Запуск и перезапуск системы:** доработана страница, отображаемая во время запуска **Comindware Platform** и обновления базы данных: страница автоматически обновляется, пока сервисы не будут готовы, отображает состояние обновления базы данных и после завершения запуска переводит пользователя на страницу входа.
- **Виджеты:** улучшено отображение данных.

### Формы и атрибуты

- **Атрибуты «Документ» и «Изображение»:** улучшена работа в режиме редактирования формы.
- **Ссылочные атрибуты:** уточнено отображение записей в выпадающих списках: архивированные записи больше не предлагаются для выбора на форме.

### Списки и коллекции

- **Коллекции:** значения связанных справочников отображаются в коллекциях независимо от того, архивирована ли запись справочника.
- **Таблицы с группировкой:** улучшена работа формы расширенного поиска.

### Переменные, сценарии и язык выражений

- **Параметры сеанса:** добавлен признак устройства, с которого пользователь работает с системой (веб-интерфейс, мобильное приложение, мобильный веб-сайт, форма для внешних пользователей). Новый параметр доступен в языке выражений и позволяет настраивать правила отображения форм в зависимости от устройства пользователя, в том числе использовать его в вычисляемых атрибутах при работе через мобильный интерфейс.
- **Сценарии:** улучшена работа блока создания документа по шаблону внутри цикла по объектам.

### Корпоративная архитектура и процессы

- **Конструктор диаграмм:** улучшено отображение при переключении между режимами просмотра и редактирования; повышена стабильность работы с версиями.

### Интеграции и пути передачи данных

- **Адаптеры и брокеры сообщений:**
  - повышена стабильность работы с брокерами сообщений;
  - реализован двусторонний маппинг альтернативных имён шаблонов и атрибутов в адаптере Apache Kafka;
  - улучшена работа кластерной конфигурации.
- **Импорт и экспорт данных:**
  - улучшен импорт данных в **Comindware Platform**;
  - повышена надежность экспорта записей через адаптер передачи данных при наличии атрибутов, хранящих несколько значений.
- **Пути передачи данных:** повышена стабильность работы при выборе связанных ссылочных атрибутов из одного шаблона записи.

### Производительность

- **Формы:** повышена производительность операций с формами, содержащими большое количество виджетов.

## Исправления

- **Инфраструктура и интеграции:** повышена стабильность работы адаптеров, брокеров сообщений, кластерной конфигурации, импорта и экспорта данных.
- **Приложения и интерфейс:** улучшена работа форм, списков, коллекций, виджетов, сценариев, конструктора диаграмм и **Корпоративная архитектура**.
